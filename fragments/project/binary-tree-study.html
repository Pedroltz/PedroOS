Problema Abordado

Compreender a organização de árvores binárias de busca e seus algoritmos fundamentais.

Solução Desenvolvida

Implementações em duas linguagens que permitem inserir valores, pesquisar elementos e percorrer a árvore em ordem crescente.

Descrição e detalhes técnicos

Projeto didático com implementações de uma árvore binária de busca (BST) em Python e C++, com menu de texto para interação com a estrutura de dados.

  • Inserção e busca respeitando a ordenação da árvore.
  • Percurso em ordem para exibir os valores ordenados.
  • Menu de console para experimentar as operações.
Tecnologias utilizadas
  • Python
  • C++
  • Estruturas de dados
  • Árvore binária de busca
