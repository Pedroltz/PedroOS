Problema Abordado

Organizar tarefas pessoais com acesso autenticado e acompanhamento de prioridade, prazo e situação.

Solução Desenvolvida

Interface Angular com cadastro e login via Firebase, proteção de rotas e operações de criação, edição, exclusão e listagem de tarefas por usuário.

Descrição e detalhes técnicos

Aplicação web para cadastro de usuários e gerenciamento de tarefas pessoais. O frontend Angular utiliza componentes standalone, formulários e HttpClient, integrado a uma API ASP.NET Core com Entity Framework Core e SQL Server.

  • Cadastro e login com Firebase Authentication e validação de token no backend.
  • Gerenciamento de tarefas por usuário, com prioridade, prazo e situação.
  • Frontend organizado em páginas e componentes standalone.
Tecnologias utilizadas
  • Angular
  • TypeScript
  • .NET 9
  • ASP.NET Core Web API
  • Entity Framework Core
  • SQL Server
  • Firebase Authentication
