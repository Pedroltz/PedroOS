Aventura textual interativa ambientada em 2091, executada em console com motor narrativo baseado em arquivos JSON e persistência de estado.

  • Motor narrativo dirigido por dados JSON e sistema de save/load.
  • Jogo C# original executado no backend, com interface de terminal dentro do Terminal PedroOS do PedroOS.
