Problema Abordado

Configurar e manter servidores xrdp multiusuário no Linux exige edição manual de arquivos de sessão, ajustes de PolicyKit, verificação de dependências e configuração de wrappers para publicar aplicativos Linux ou Windows via RemoteApp.

Solução Desenvolvida

Aplicação desktop centralizada com gerenciamento de contas RDP, seleção de ambientes (KDE Plasma, GNOME, XFCE), publicação de Linux RemoteApp e aplicativos Windows via umu, centro de diagnóstico (`rdpsm health`) e reparo automático com rollback e trilha de auditoria em JSONL.

Descrição e detalhes técnicos

Interface gráfica nativa em GTK 4 e libadwaita para administração de acesso remoto via xrdp em distribuições Linux (Ubuntu, Debian, Arch e derivados). Centraliza criação e controle de usuários RDP, configuração de sessões desktop ou RemoteApp, execução de aplicativos Windows via umu/Wine, diagnóstico de saúde e reparo transacional.

  • Gerenciamento completo de usuários RDP (criação, ativação, desativação e remoção).
  • Suporte a sessões completas (KDE, GNOME, XFCE), Linux RemoteApp e aplicativos Windows via umu/Wine.
  • Centro de saúde (`rdpsm health`) com reparo transacional, rollback automático e auditoria JSONL.
  • Monitoramento de sessões e verificação/instalação assistida de dependências por distribuição.
