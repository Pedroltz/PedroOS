Problema Abordado

Organização e leitura centralizada de acervos de quadrinhos/mangás com controle administrativo.

Solução Desenvolvida

Aplicação MVC com persistência relacional em PostgreSQL, controle de acesso e leitor web integrado.

Descrição e detalhes técnicos

Aplicação web desenvolvida em ASP.NET Core 8 MVC com Entity Framework Core e PostgreSQL para catalogação, administração e leitura de capítulos, com autenticação e área administrativa.

  • Catálogo, leitor web e área administrativa com autenticação.
Tecnologias utilizadas
  • C#
  • ASP.NET Core 8 MVC
  • Entity Framework Core 9
  • PostgreSQL 15
