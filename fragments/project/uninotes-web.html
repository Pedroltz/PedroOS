Problema Abordado

Manter anotações e informações acadêmicas organizadas e acessíveis em um único ambiente.

Solução Desenvolvida

Interface web para cadastro e organização de notas em pastas, consulta do conteúdo e integração com a API acadêmica.

Descrição e detalhes técnicos

Frontend web desenvolvido em Angular e TypeScript, com Bootstrap, para cadastrar e consultar anotações acadêmicas organizadas em pastas. Integra-se a um backend .NET 6 mantido em repositório separado.

  • Cadastro de anotações e organização por pastas.
  • Frontend Angular integrado a uma API .NET 6.
  • Backend documentado no repositório ViiKDev/uninotes-api.
Tecnologias utilizadas
  • Angular
  • TypeScript
  • Bootstrap
  • .NET 6 (API integrada)
  • Entity Framework Core (API integrada)
